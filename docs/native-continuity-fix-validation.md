# 原生上下文接续修复与验证

日期：2026-09-10。

状态：源码修复与本地验收完成；不代表已安装、发布，或已验证外部模型的自主行为。

## 修复范围

沿用原生 Claude Code、私有 tmux、会话本地 hooks 和现有 History/Notes CLI：

- 自动操作暂停后，仍接受并核对迟到的真实 `SessionStart`，更新会话绑定并登记历史；正常 hook 继续观测用量，明确显示暂停原因。
- 在 `PostToolBatch` 之后、下一次模型请求前检查预算。当前直接调用结算即可换窗，不必等待后台任务全部结束。
- 换窗通过原生后台消息通道投递，以真实新会话事件和接续消息入史确认完成，不靠延迟或输入框外观推断成功。
- 已提交但尚未执行的输入保留在原生历史中，接续携带准确定位，按顺序处理；不另建用户输入队列，不将交接记录当成新增授权。
- 保留后台任务句柄和最近记录定位，避免为恢复结果重跑任务。未提交草稿不由控制器读取或改写。
- 支持的超大 Bash、文本 Read 和已完成 Agent 结果保留完整脱敏存档，返回有界预览。多模态结果不按 base64 字节冒充文本 token；不能忠实替换的结果交由批次边界处理。
- History/Notes 在整个任务期间通过原有 CLI 使用，历史登记不依赖模型是否主动保存交接。
- 控制器恢复前核对对应会话的原生通道环境与凭证。缺少凭证时不启动进程、不改运行状态；凭证只在进程环境中传递，不写入状态或报告。

已移除新增的 History/Notes MCP 实现、专属测试、插件注册、工具发现指引和字节码缓存。旧的 tmux 输入框注入函数及专属测试也已移除。`native_control.py` 与 `result_budget.py` 属于原定修复，不是 CPA 替代方案；未来探索仍单独保留在 [Codex/Pi 评估文档](future-codex-context-integration.md)。
